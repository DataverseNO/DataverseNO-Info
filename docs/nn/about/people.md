# Folk

DataverseNO blir støtta av eit nasjonalt nettverk av folk som arbeider med forskingsdatastøtte, kuratering, samlingsforvaltning, og arkivforvaltning.

På denne sida kan du bli betre kjend med folka som står bak DataverseNO, og finna ut meir om kva rolle, institusjonstilhøyrsle og kompetanseområde dei har. Oversikta omfattar støttepersonell på DataverseNO-partnarinstitusjonar, medlemmar av samlingsforvaltninga, kuratorar, arkivforvaltninga, styremedlemmer og andre som bidreg til å utvikla og forvalta DataverseNO som eit trygt arkiv for opne forskingsdata.

Bruk søkje- og filtervala nedanfor for å utforska DataverseNO-nettverket etter institusjon, rolle, namn, kompetanse eller nøkkelord.
