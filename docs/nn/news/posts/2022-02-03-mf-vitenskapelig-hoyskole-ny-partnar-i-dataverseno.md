# MF vitenskapelig høyskole ny partnar i DataverseNO

DataverseNO ønskjer MF vitenskapelig høyskole velkommen som partnarinstitusjon. Med si eiga institusjonssamling ( [https://dataverse.no/dataverse/mf](https://dataverse.no/dataverse/mf) ) i DataverseNO kan MF no tilby eigne forskarar eit sertifisert og kuratert datarkiv der dei kan gjera dataa sine ope tilgjengelege og dermed gjera forskinga meir synleg, og fremja kompetanse på open forsking.
