# Ledig stilling som arkivforvaltar i DataverseNO

Vi styrkjer laget og søkjer ein initiativrik og omgjengeleg arkivforvaltar med ambisjonar om å bidra til å sikra og løfta nivået på DataverseNO til å kunna tilby forskarar frå norske institusjonar eit påliteleg og framtidsretta arkiv for forskingsdata i verdsklasse. Meir informasjon i [utlysinga](https://www.jobbnorge.no/nn-no/ledige-stillingar/stilling/285893/arkivforvaltar-for-forskingsdataarkivet-dataverseno).
