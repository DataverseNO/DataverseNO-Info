# VID vitenskapelige høgskole ny partnar i DataverseNO

DataverseNO ønskjer VID vitenskapelige høgskole velkommen som partnarinstitusjon. Med si eiga institusjonssamling ( [https://dataverse.no/dataverse/vid](https://dataverse.no/dataverse/vid) ) i DataverseNO kan VID no tilby eigne forskarar eit sertifisert og kuratert datarkiv der dei kan gjera dataa sine ope tilgjengelege og dermed gjera forskinga meir synleg, og fremja kompetanse på open forsking.
