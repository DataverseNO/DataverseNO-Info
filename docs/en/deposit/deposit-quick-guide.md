# Quick Guide and Checklist

This checklist provides a condensed overview of the DataverseNO deposit workflow. For detailed guidance, follow the links to the full [PAGE: deposit/index | deposit guidelines].

Use the checklist to track the main tasks before, during, and after depositing a dataset in DataverseNO.

## [PAGE: prepare-your-data | Step 1: Prepare your data]

[ ] File naming and organization

- Follow [PAGE: prepare-your-data#organize-your-files | good practice for file naming and organization].

- Follow [PAGE: prepare-your-data#spreadsheets-and-tabular-data | general recommendations for spreadsheets and tabular files].

[ ] File formats

- Choose a [PAGE: prepare-your-data#choose-suitable-file-formats | preferred file format] that is suitable for long-term preservation where possible.

- If both the original format and a preferred format are provided, use identical file names except for the file extension.

[ ] ReadMe file

- Describe your data in a [PAGE: prepare-your-data#describe-your-data | ReadMe file], using a template: [REUSE: links/dataverseno-readme-template-general | general] or [REUSE: links/dataverseno-readme-template-code | for code].

- Save the ReadMe file in plain text format, for example .txt or .md.

[ ] File and dataset size

- An individual file should preferably not exceed [REUSE: values/file-size-limit].

- A single upload should preferably not exceed [REUSE: values/upload-size-limit].

- A dataset should preferably not exceed [REUSE: values/dataset-size-limit].

- A dataset should preferably not contain more than [REUSE: values/file-number-limit].

- For larger files or datasets, contact your [REUSE: links/contact-page | local user support].

## [PAGE: deposit-your-data | Step 2: Deposit your data]

[ ] [PAGE: deposit-your-data#create-a-user-account | Create a user account, if needed]

[ ] [PAGE: deposit-your-data#create-a-dataset-draft | Create a dataset draft]

- Confirm that you are in the correct collection for your dataset. If not, navigate to the appropriate collection before continuing.

- Click Add Data and select New Dataset.

[ ] [PAGE: deposit-your-data#describe-your-dataset-using-metadata | Enter metadata]

- Enter as much metadata as possible, and at minimum fill in the [PAGE: deposit-your-data#required-metadata | required fields].

- Remember to click Save Dataset at the bottom of the page.

[ ] [PAGE: deposit-your-data#choose-terms-for-reuse | Confirm or specify a licence]

- The standard recommended licence is [PAGE: deposit-your-data#recommended-licence | CC0]. If no suitable licence is available, contact your [REUSE: links/contact-page | local user support].

[ ] [PAGE: deposit-your-data#upload-your-files | Upload your files]

- Open the Files tab and click Upload Files.

- To upload single files, click Select Files to Add.

- To preserve folder structure, use Upload a Folder.

- Click Save when you are done.

[ ] [PAGE: deposit-your-data#share-your-dataset-before-publication | Share your dataset before publication, if needed]

- Need to share a dataset before publication, for instance with collaborators or peer reviewers? Contact your [REUSE: links/contact-page | local user support].

[ ] [PAGE: deposit-your-data#submit-your-dataset-for-review | Submit your dataset for review]

- Prepared your data according to the guidelines? Click Submit for Review.

- Remember that your dataset is still a draft. The dataset [REUSE: terms/digital-object-identifier | DOI] is not active yet.

## [PAGE: publish-your-data | Step 3: Curation and publishing]

[ ] [PAGE: publish-your-data#the-curation-process | Curation]

- A curator from your institution will review your dataset and, if necessary, tell you what should be changed before publication.

- You will normally receive an initial response from a curator within three working days after submitting the dataset for review.

- If needed, make the recommended changes. Alternatively, explain why you do not agree with specific recommendations.

- When you are done with the revision, click Submit for Review again.

[ ] [PAGE: publish-your-data#get-your-dataset-published | Get your dataset published]

- Once the curator has approved the dataset and you have confirmed it is ready for publication, the curator will publish it.

- The dataset DOI is now active.

## [PAGE: refer-to-your-data | Step 4: Refer to your data]

[ ] Refer to your published dataset

- Use the recommended citation provided by the repository at the top of the dataset page.

- Cite the dataset in publications by including it in the reference list and data availability statement, and by citing it in the text where relevant.

## [PAGE: modify-your-data | Step 5: Modify your data]

[ ] Modify your published dataset, if needed

- It is possible to [PAGE: modify-your-data | modify your dataset] after publication.

- Updating a published dataset creates a new version that must be reviewed before publication.

- Previous versions remain accessible.
